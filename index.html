    ABOUT THE PROJECT
    Executive Summary The Smart Home Safety System is an IoT-inspired home monitoring dashboard designed to demonstrate how sensor-based monitoring can improve household safety. It represents a smart monitoring environment with door security, gas leakage detection, and water-level monitoring through a unified interface.
    SECURITY MATRIX
    Smart Door Security
    • Simulates door status using a Reed Switch.
    • Displays LOCKED and UNLOCKED states.
    • Demonstrates access-status monitoring.
    ATMOSPHERE
    Gas Leakage Monitoring
    • Represents an MQ-2 gas sensor.
    • Displays simulated gas concentration levels.
    • Provides safe, warning, and danger alerts.
    RESERVOIR
    Water Level Monitoring
    • Represents an HC-SR04 ultrasonic sensor.
    • Displays simulated water tank levels.
    • Demonstrates high-level and overflow warnings.

    KEY FEATURES
    FT-01
    Real-Time-Style Monitoring
    Simulated sensor stream updates telemetry synchronously without requiring backend servers.
    FT-02
    Automatic Sensor Fluctuations
    Integrated random walk models ambient noise, natural ventilation decay, and reservoir drainage.
    FT-03
    Interactive Manual Overrides
    Direct control buttons for door, gas, and water with an intelligent 15-second grace hold period.
    FT-04
    Dynamic Tri-Tier Alerts
    Automated threat escalation into Safe (green), Warning (amber), and Danger (pulsing red) states.
    FT-05
    Animated Gas-Level Gauge
    Custom HTML5 Canvas radial gauge with dynamic color zones, tick marks, and needle physics.
    FT-06
    Animated Water Tank
    Fluid level visualization featuring SVG dual-wave motion and reactive overflow warning thresholds.
    FT-07
    Live Digital HUD Clock
    Synchronized digital time and calendar display formatted in futuristic Share Tech Mono typography.
    FT-08
    Dark & Light Theme Switcher
    Seamless one-click theme switching driven by CSS custom properties and Canvas color re-rendering.
    FT-09
    Persistent Activity Log
    Safe DOM event recording with severity tags, individual deletion, and localStorage persistence.
    FT-10
    Pause & Resume Simulation
    Interactive toggle lets reviewers freeze the simulation engine to inspect UI states in detail.
    FT-11
    Responsive Dashboard Interface
    Fluid layouts with CSS grid and flexbox, fully optimized across 4K displays, tablets, and phones.

    CLIENT-SIDE SIMULATION ENGINE
    JavaScript Telemetry Generator · Realistic Jitter, Spikes & Override Grace Periods
    Architectural Summary: The dashboard uses client-side JavaScript to simulate physical sensor readings and update the interface in real time. Decoupling the frontend presentation layer from physical hardware enables instant portfolio demonstration with zero server latency, zero cloud costs, and complete offline availability.

    PROTOTYPE SPECIFICATION: The components below represent the original physical IoT hardware specifications. In this portfolio demo, all sensor telemetry is simulated client-side. No physical hardware is currently connected.
